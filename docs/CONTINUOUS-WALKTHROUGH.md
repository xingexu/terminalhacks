# Navigation scope

The accepted demo uses Google Maps JavaScript Street View, with transitions between available panorama positions. It is not a continuous reconstructed3D world. The earlier projected-photo experiment is not the selected experience.

W/S follow connected panorama links; A/D turn; dragging looks around. Native VoiceOS calls the same navigation controller. Reviewed named stops provide the verified Le Shack entrance, interior and return path. Google/photographer attribution remains visible.

See [current demo instructions](DEMO.md), [implementation](STREET-VIEW-IMPLEMENTATION.md), and [acceptance status](ACCEPTANCE.md).
